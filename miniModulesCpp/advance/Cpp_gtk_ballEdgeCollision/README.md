## Feature
1. Button Up: To change color all of Ball.
2. Button Down: To reverse all of direction Ball
3. Button Right: To speed Up all of Ball
4. Button Left: To speed Down all of Ball
5. Fixed bug: When resize window. That can be loss some Ball.
